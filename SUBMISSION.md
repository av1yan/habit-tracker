# App Store submission checklist

Ordered path to “Submit for Review” on App Store Connect. Code is submission-ready;
the remaining items are account/dashboard/asset steps. Check them off in order —
later steps depend on earlier ones.

## 1. Backend & config (do first — the build's features depend on these)

- [ ] **Supabase → Auth → Providers → Apple:** enable, add bundle id
      `com.av1yan.habittracker` to the authorized client IDs (native Sign in with
      Apple needs no client secret).
- [ ] **Supabase → Auth → URL Configuration:** add the password-recovery redirect
      URL (`habittracker://reset-password`) so the reset email deep-links back.
- [ ] **Supabase → Auth:** confirm **email confirmation** is on; enable
      **leaked-password protection** (Auth → Passwords).
- [ ] **Supabase:** upgrade off the free tier (no auto-pause / backups for live users).
- [ ] **Legal:** fill every `[BRACKET]` in `legal/*.md`, get a legal review, then
      `npm run build:legal`.
- [ ] **GitHub → Settings → Pages:** deploy from branch `main` / `/docs`, so the
      Privacy Policy + Terms URLs resolve (App Store requires a working Privacy URL).
- [ ] *(optional)* **Sentry / PostHog:** set the EAS env vars from `MOBILE.md`
      to turn on crash reporting / analytics in the release build.

## 2. Assets

- [ ] Replace the placeholder **app icon** with real 1024×1024 artwork (+ splash).
      Current icon is generated by `scripts/generate-icons.mjs`.
- [ ] **Screenshots** — 6.7" iPhone required (1290×2796); 6.5" optional. Capture
      Today, Garden, Calendar, and Stats in both light and dark.

## 3. Build

- [ ] `eas login && eas init` (links the project, writes `extra.eas.projectId`).
- [ ] `npm run build:ios` (production profile). EAS registers the app on your
      Apple account and provisions signing automatically.

## 4. Verify on a real device / TestFlight

These only run on a dev/prod build, not Expo Go — verify them:
- [ ] Sign in with Apple (name captured on first sign-in)
- [ ] Local reminder notifications fire at the scheduled time
- [ ] Share-card exports a real PNG (not just the text fallback)
- [ ] Sign-up → email confirmation → sign-in, and password reset deep link

## 5. App Store Connect

- [ ] Create the app record (bundle id `com.av1yan.habittracker`); category
      **Health & Fitness** (alt: Productivity).
- [ ] Paste listing copy (below); upload icon + screenshots; set the Privacy URL.
- [ ] **App Privacy** questionnaire — declare: Email, User ID, Product Interaction
      / Usage Data, Crash/Diagnostics. Mark **“Data not used to track you.”**
- [ ] Age rating questionnaire (expect 4+).
- [ ] `npm run submit:ios` to upload the build, attach it, then **Submit for Review**.

# App Store listing copy

Suggestions — tune to taste. Character limits noted; Apple enforces them.

**App name** (≤30) — `Habits — Streak Garden`

**Subtitle** (≤30) — `Build habits, grow a garden`

**Keywords** (≤100, comma-separated) —
`habit,tracker,streak,routine,daily,goals,productivity,reminder,garden,wellness,checklist,journal`

**Promotional text** (≤170) —
`Turn daily habits into a thriving garden. Keep your streak alive, watch each habit grow, and stay motivated — private, offline-first, no ads.`

**Description** (≤4000) —

```
Build habits that stick — and watch them grow.

Habits turns your daily routines into a living garden: every habit is a plant that
grows the longer you keep its streak alive, from a tiny seed to a mighty tree. It's
a habit tracker that actually makes consistency feel rewarding.

WHY YOU'LL LIKE IT

• Grow a garden — each habit becomes a plant that levels up with your streak. Your
  progress, made visible.
• Keep the streak — check off habits daily and build streaks. Life happens, so use
  a Streak Freeze to protect a streak on a day you miss.
• See your progress — a month calendar and activity heatmap, per-habit stats, and
  milestone achievements that celebrate every step.
• Gentle reminders — set a custom time (and days) per habit; nudges arrive right
  on your phone.
• Build or quit — track habits you want to grow, or ones you want to break.
• Yours, everywhere — offline-first, so it works without signal and syncs across
  your devices when you're back online.
• Beautiful in any light — warm design with full light and dark modes, custom
  icons, colors, and categories.

PRIVATE BY DESIGN

No ads. No cross-app tracking. No selling your data. Sign in with Apple or email,
and delete your account and all its data anytime, right from the app.

Plant your first habit today and watch your garden grow. 🌱
```

**Support URL** — your support page or the repo issues URL.
**Marketing URL** (optional) — a landing page, if you make one.
